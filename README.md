# 计算破局者：混合运算技巧

七年级有理数混合运算自主学习网站，支持中文和中英双语。

网站：https://ding0180.github.io/calculation-breakthrough/

- 五个核心技巧：加法配对、乘法配对、分配律、小数转分数、乘方与符号。
- 观察例题逐行展开，保留完整计算过程、颜色提示与简短讲解。
- 每个技巧配有三道练习，综合运用包含三道例题和六道练习。
- 学习进度、答案草稿和订正记录保存在当前浏览器，可导出学习记录。

## 发布

GitHub Pages 从 main 分支根目录发布。index.html 内含页面所需的 CSS 和 JavaScript，无需安装或构建。更新 index.html 并推送到 main 后，GitHub Pages 自动发布。

不同设备或浏览器的学习记录不会自动同步；本地文件版的记录不会自动迁移到网站。

## 师生记录

学生先填写姓名进入学习，网页顶部的“导出成绩链接”会自动使用登录姓名生成成绩快照。复制完整链接，手动发送给教师；订正后需重新生成。链接片段包含学生标识、姓名、六部分前台用时、各轮首次与后续逐题结果，以及出门条记录；不包含原始答案、个人笔记或账号密码。

教师入口：https://ding0180.github.io/calculation-breakthrough/teacher.html

教师输入约定密码后进入导入与分析页面。两个版本均支持退出登录，同一标签页刷新保留登录状态，退出后再次进入需要重新登录。退出不会删除已有学习记录或教师已导入的数据。姓名用于标识当前设备的学习记录，不是独立账号；教师密码为静态网页入口校验，不提供服务器级访问控制。

教师可批量粘贴完整链接或含链接的群聊文本。重复快照不重复计数；同一学生的多次导出保留历史，默认统计最新导出快照的当前轮次；同名不同标识分开显示。同时间冲突保留双方并标记待核对。未提交与已提交的零分分开显示，空题计入正确率分母。教师端也提供课程与解析、逐题表现、教师备份及恢复。

所有导入数据仅保存到教师当前浏览器，不上传到服务端。分享链接中的数据可被获得链接的人读取；链接不是身份认证或考试防作弊凭证。页面只统计已导入学生，时间为前台停留时长。
